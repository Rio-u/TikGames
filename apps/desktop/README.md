# TikGames Desktop (Electron)

النسخة المكتبية من TikGames — برنامج `.exe` واحد بيبعته للستريمر، هو بس يفتحه ويكتب باسورد
التفعيل ويلعب. مش محتاج ينزّل Node ولا Python ولا أي حاجة.

## إزاي بيشتغل (الأمان)

الفكرة كلها إن **مفيش أي سر جوّه الـ exe**. البرنامج عميل خفيف بيكلّم السيرفر بتاعك بس:

```
  الـ exe عند المستخدم              apps/api (السيرفر بتاعك)            ديسكورد
  شاشة التفعيل (باسورد)  ─────►  POST /licensing/register  ─────►  إشعار + الأوامر
  بصمة الجهاز (هاش)                LicenseDevice(PENDING)           /approve /block /kill
  نبضة كل 30 ثانية      ─────►  POST /licensing/heartbeat ◄─────  الحالة بتتغير فوراً
  يفتح الداشبورد أول ما يتوافق عليه
```

- **الباسورد**: المستخدم بيكتبه، والسيرفر هو اللي بيتأكد منه. مش متخزّن في الـ exe.
- **توكن بوت الديسكورد**: موجود **بس** في `.env` بتاع السيرفر. لو حد فكّ الـ exe مش هيلاقي أي
  حاجة تنفعه — لا توكن، ولا طريقة يوافق على جهازه بنفسه.
- **الأجهزة**: كل جهاز بياخد هاش ثابت من مواصفاته (مش الـ MAC نفسه — الهاش بس). أنت بتوافق على كل
  جهاز يدوي من ديسكورد.
- **القفل عن بُعد**: `/block` أو `/kill` بيحوّل الجهاز لـ BLOCKED، والنبضة الجاية (خلال ثواني)
  بتقفل البرنامج عند المستخدم وترجّعه لشاشة التفعيل.
- **الخصوصية**: بنسجّل اسم الجهاز واسم المستخدم في النظام وهاش مشفّر — الحد الأدنى لإدارة
  التراخيص، ومكتوب للمستخدم في شاشة التفعيل. **مش** بنقرأ ملفاته ولا بياناته الشخصية.

> ملحوظة صريحة: "التشفير الكامل" في برنامج Electron معناه TLS في النقل + توكنات موقّعة + مفيش
> أسرار في العميل. كود الواجهة نفسه دايماً ممكن يتفك — الأمان الحقيقي على السيرفر، وده اللي عملناه.

## إعداد السيرفر (مرة واحدة)

في `apps/api/.env`:

```bash
LICENSE_PASSWORD="الباسورد اللي هتديه للناس"   # فاضي = محدش يقدر يفعّل (fail-closed)
LICENSE_AUTO_APPROVE=""                          # سيبها فاضية عشان توافق يدوي؛ "1" = تفعيل تلقائي
DISCORD_BOT_TOKEN="توكن البوت"                   # من https://discord.com/developers
DISCORD_GUILD_ID="آي دي السيرفر بتاعك"           # عشان الأوامر تظهر فوراً
DISCORD_ADMIN_USER_IDS="آي ديك,آي دي أدمن تاني"  # مين مسموح له بالأوامر (فاضي = محدش)
DISCORD_ADMIN_LOG_WEBHOOK_URL="..."               # (اختياري) قناة اللوجز والإشعارات
```

البوت بيشتغل تلقائياً مع الـ API لو `DISCORD_BOT_TOKEN` موجود. لازم تعمل invite للبوت على سيرفرك
بصلاحية `applications.commands`.

### أوامر ديسكورد (للأدمن المسموح لهم بس)

| الأمر | بيعمل إيه |
|---|---|
| `/pending` | الأجهزة اللي مستنية موافقة |
| `/devices [status]` | كل الأجهزة (تقدر تفلتر pending/approved/blocked) |
| `/approve <id>` | تفعيل جهاز — بيدخل خلال ثواني |
| `/block <id> [reason]` | قفل / رفض جهاز (زرار الإيقاف) |
| `/kill <id>` | نفس `/block` |
| `/reactivate <id>` | إلغاء القفل |

`<id>` هو المعرّف القصير (٨ حروف) اللي بيظهر في `/devices` — بادئة منه تكفي طول ما هي فريدة.

## إعداد العميل قبل ما تبني الـ exe

`apps/desktop/config.json` — غيّر الرابطين لسيرفرك المنشور:

```json
{ "apiUrl": "https://your-api.onrender.com", "dashboardUrl": "https://your-dashboard.vercel.app" }
```

تقدر كمان تعدّل نفس الملف جنب الـ exe بعد التوزيع من غير ما تعيد البناء.

## البناء

```bash
pnpm --filter @tikgames/desktop dev     # يفتح البرنامج محلياً للتجربة
pnpm --filter @tikgames/desktop dist    # يطلّع المثبّت (.exe) في apps/desktop/release/
```

المثبّت اللي بيطلع **مش موقّع** (unsigned) — أول مرة المستخدم يفتحه ويندوز SmartScreen ممكن
يحذّر؛ يدوس "More info → Run anyway". لو عايز تشيل التحذير ده محتاج شهادة توقيع كود مدفوعة.
